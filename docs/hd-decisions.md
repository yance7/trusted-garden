# 本轮实施取舍

1. 在隔离 worktree 开发，主分支和生产基线保留；代价是验收后需要合并，当前目录不会直接变成生产版本。
2. 用户已批准设计并要求实施，使用本轮直接执行和一次独立总审查，不再次请求同一实施授权；代价是过程中的常规技术选择由执行者负责。
3. 全部原生 4K 表面材质和高精度几何优先，用户已取消原下载 / 显存预算；代价是加载量和显存需求增加，仍提供性能档。
4. 使用 WebP 与 Meshopt，本次不宣称 KTX2、流式加载或几何 LOD 已完成；代价是 GPU 纹理内存与完整场景加载仍有后续优化空间。
5. GLB 几何与 4K 纹理分开，同站点托管；代价是下载模型时必须同时保留 textures 文件夹，换来无单文件上限导致的画质压缩。
6. 性能档降低输出、阴影和后处理而保留原生模型 / 材质；代价是低端设备仍需足够内存，但不会改变几何细节基准。
7. 列为 Minor 的数字键同步、Escape、热点和导览时钟仍影响已承诺操作，本轮按功能回退处理并修复；复现检查先失败后通过，无遗留审查阻塞项。
8. 人物使用可复现的骨骼技术员和简化地面 / 碰撞逻辑；代价是它仍需艺术质量验收，不被标为影视角色或精准物理模拟。
9. 对当前源模型的坐标、单 primitive 和未变换节点建立明确契约，不扩展成通用 glTF 编辑器；若未来换源资产，需要先扩展导入契约和测试。
10. 发布前保留用户视觉确认；本轮未自行修改域名、DNS、生产站点或主分支。
