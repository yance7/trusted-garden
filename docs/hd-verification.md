# V0.8 HD 本地验证记录

日期：2026-10-29。开发分支 `feature/v08-hd`，生产 V0.8 尚未合入或发布。

## 已完成的证据

- 原始对象完整覆盖：2,624 个，稳定 ID 无重复；GLB 生成 NORMAL / TEXCOORD_0，材质文件全部存在。
- 当前静态模型：947,314 个三角面，311 个语义批次；286 个设备附加部件，曲面草叶 113,856 个三角面。
- 4K 实拍混凝土 / 木材 / 树皮 / 泥土；4K 程序叶片 / 金属微表面 / 水面法线。粗糙度 / 金属度按通道正确处理。
- 模型与独立骨骼人物均从源生成器导出；网页加载相同资产。纹理保留在模型旁，避免为单文件体积降低分辨率。
- `npm test`：7 项行为 / 资产契约通过，包含坐标方向、HeroCorn 区域归属、量化变换与生长、碰撞、滑行和漫游快捷键。
- `npm run typecheck` 与 `npm run build`：通过。
- 正式构建的 `/trusted-garden/` 子路径浏览器回归：通过，页面错误为零。覆盖八视点、七天气、三画质、七图层、四场景、抽屉、三弹窗、导览、生长 / 时间、拍照、真实 PNG 下载、漫游 / 第一人称及加载失败重试。
- 已获取八个固定视点、1920x1080 干净场景与三个日照状态、人物视角、窄屏和 DPR2 截图，以及浏览器录像。证据保存在本地 `evidence/`，不上传网站。

## 硬件与帧时

浏览器识别到 Intel Arc B390 / Direct3D11。之前 SwiftShader 仅用于正确性检查；性能报告使用真实硬件加速。

第一组带录像、静止全景、每档 30 秒的 rAF 帧时：Performance 输出 1600x900，均值 8.33 ms，p95 8.5 ms；High 输出 1920x1080，均值 11.05 ms，p95 16.8 ms。此组仅作带录制开销的静态场景记录，不代表所有漫游路径。

另运行不录像的八视点固定路径测试，最终结果写入 `evidence/benchmark-path.json`。这里统计浏览器 rAF 帧间隔，不将其冒充 GPU 时间查询，也不推广为其他机器的帧率保证。

## 本次明确的取舍

- 用户取消资源体积限制，使用完整原生 4K 材质。性能档降低内部输出、阴影与 AO，保留高精度模型与材质。
- 使用本地 WebP 与 Meshopt；当前没有 KTX2、按区流式加载或几何 LOD，不宣称这些已完成。
- 保留场地结构与模拟数据声明；人物为可复现的骨骼技术员，仍需用户对整体艺术质量验收。
- 本次没有修改 DNS、域名、线上网站或主分支内容。
