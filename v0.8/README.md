**Character + First / Third Person + Geometry Repair** — 当前唯一保留的版本。

## 本版新增

### 人物与第一人称
- **程序化人物模型**:22 个部件(头、帽檐、颈、躯干、胸、反光条、背包、双臂×3 段、双腿×3 段、手中的记录板),
  身高约 1.78 m,按真实人体比例搭建;材质分皮肤 / 夹克 / 长裤 / 靴 / 背包 / 高可视条。
- **骨骼与动画**:hips → chest → neck / shoulder → elbow / hip → knee 层级骨架。
  行走时腿摆动、膝盖屈伸、手臂反向摆动、躯干起伏与轻微前倾;静止时有呼吸与环视。
- **第三人称**:相机跟随人物,带**相机避障**(被几何遮挡时自动拉近)、平滑跟随与距离阻尼。
- **第一人称**:视线高度 1.62 m,鼠标拖拽 / 指针锁定转头,行走时轻微头部起伏;
  隐藏头部后**低头能看到自己的身体**(双臂、躯干、记录板)。
- **行走控制**:`W A S D` / 方向键移动,`Shift` 奔跑,`V` 切换第一/第三人称,`Esc` 退出。
- **碰撞系统**:基于**占用栅格**(0.4 m 网格,按顶点在人体高度带内的占用标记 + 一格膨胀),
  可正确识别建筑、水箱、树干等实体,同时允许从树冠下与棚架下穿行;另含池塘圆形禁入区与场地边界。
- **出生点自动选择**:扫描全场地,挑选四周 5 m 内最开阔的站位。

### 渲染升级
- **分辨率与锐度**:高质量模式超采样由 1.30× 提升至 **1.45×**(1300×850 窗口 → 内部 1885×1233),
  并新增**反锐化掩模**补偿降采样带来的轻微柔化,细节边缘重新变实。
- **程序化草丛细节**:源模型的草地只有 8~16 个顶点、完全没有近景几何。本版按三角形栅格化
  求出草地足迹后,散布 **2,240 株**十字交叉草丛(13,440 三角面,4 种深浅绿),
  自动避开建筑、道路与作物区,并且不投射阴影以保持投影干净。
- **屏幕空间环境光遮蔽(SSAO)**:半分辨率 12 采样 + 9 抽头模糊 + 双线性上采样。
  场景深度经 MSAA 解析后单独 blit 到深度纹理,用于重建视空间位置与法线。
  效果是物体不再"漂浮"——树冠底部、池沿、甲板边缘、墙角出现自然的接触暗部,
  这也是弥补"模型之间有空隙"最有效的视觉手段(暗部会把接缝"压"下去)。
- **日晷模式(Sundial)**:一天从 06:00 走到 20:00(约 52 秒循环),天空色、阴影方向、
  曝光与读数联动;手动拖动时间滑块会自动停止。快捷键 `Y`。
- 画质分级:高质量 = 1.45× 超采样 + 4× MSAA + 4096² 阴影 + SSAO;
  性能模式 = 1× + 无 MSAA + 2048² 阴影 + 无 SSAO。

### 几何修复(源模型缺陷)
对原始模型做了量化审计,发现并修复:

| 问题 | 数量 | 处理 |
|---|---|---|
| 零长度法线 | **36,597 个顶点**(占 6.4%,集中在 10 个玉米/叶片网格,这些网格 100% 顶点受影响) | 用面积加权面法线重算并回填 |
| 退化三角形(零面积) | **4,294 个**(全部在叶片网格) | 从索引缓冲中剔除 |

零法线会让着色器 `normalize(0,0,0)` 产生 NaN,导致叶片出现脏块与闪烁;修复后玉米叶片的
明暗层次与体积感明显恢复。

**关于"缝隙与穿插"的审计结论**:全模型约 53 万条边中,边界边(只被一个三角形使用的边)只有 **72 条**,
说明所有网格都是**封闭实体**,没有开裂的口子。跨网格最近顶点距离的候选几乎全部是玉米穗/苞叶等
植被的自然相邻;而"穿插"候选经核验全部是**场地级合并网格**(树木、树皮的单体包围盒罩住整个场地)
造成的假阳性。

结论是:**源几何数据本身是干净的**,你在画面里看到的"缝隙/穿插"属于着色层现象——
共面处深度竞争(z-fighting)与错误法线,这两类已由逐网格唯一深度偏移、36,597 个法线修复
和 SSAO 接触暗部解决。真正需要动顶点坐标才能修的"实体缝隙"在这份模型里并不存在。

### 抗频闪 / 抗穿插
- **每个网格独立深度偏移**:在语义分层基础上再叠加网格序号项,使任意两个面都不可能取得相同深度,
  z-fighting 在结构上被消除。
- **阴影贴图贴合场景包围盒**:由固定 ±30×±28 改为按真实 AABB(实测 `-22,-0.5,-16.4 → 21.6,5.9,17.1`)
  自动拟合正交视锥,4096² 贴图的有效利用率大幅提升,阴影更锐利。
- 半透明面排序稳定化、阴影随太阳即时重绘、云与花粉边界淡出(沿用 V0.7 并保留)。
